# CABO

Beginner-friendly scorekeeper app for the card game Cabo. This project is for learning app development while building a simple, practical app.

## Goals
- Learn Flutter and mobile app basics step by step
- Build a simple point counter with a clean UI
- Keep rules and logic easy to test and extend

## Planned Features
- Player setup (2-6 players)
- Round scoring with totals
- Cabo caller handling and rule tweaks
- Game end and winner summary

## Setup (when ready to run)
1) Install Flutter SDK and Android Studio
2) Open this folder in VS Code
3) Run `flutter doctor` and resolve any issues
4) Run the app: `flutter run`

## Notes
- iOS builds require macOS with Xcode
- This repo is intended as a learning project
